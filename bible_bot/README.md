# 📖 Библия Онлайн: Telegram-бот и Веб-приложение

Проект для удобного чтения, навигации и умного поиска по тексту Библии (Синодальный перевод). Включает в себя парсер формата FB2, Telegram-бота и полноценный веб-сайт на Flask.

## 🚀 Возможности

### 🤖 Telegram-бот
- Чтение глав по команде (например, `/read Бытие 1`).
- Автоматическое сохранение прогресса чтения в памяти.
- Команда `/next` для перехода к следующей главе.
- Быстрый поиск по ключевым словам (`/search любовь`).
- Автоматическая разбивка длинных глав на несколько сообщений.

### 🌐 Веб-приложение (Flask)
- Красивое каноническое оглавление (Ветхий и Новый Завет).
- Корректные названия разделов (например, "Псалом" в Псалтири, а не "Глава").
- Удобная навигация между главами (← Предыдущая / Следующая →).
- **Умный поиск**:
  - По одному слову: ищет только целые слова (запрос "лень" не найдёт "зелень" или "олень").
  - По фразе: ищет стихи, содержащие все введённые слова в любом порядке.
- Подсветка целевого стиха при переходе из результатов поиска (через URL-якоря).

## 🛠 Технологический стек
- **Язык**: Python 3.12+
- **Веб-фреймворк**: Flask
- **Telegram API**: pyTelegramBotAPI (telebot)
- **База данных**: SQLite3 (встроенная)
- **Парсинг**: `xml.etree.ElementTree` (для формата FB2)
- **Поиск**: Регулярные выражения (`re`) + SQL `LIKE` / `REGEXP`

## ⚙️ Установка и запуск

### 1. Подготовка окружения
```bash
cd /home/oleg/github/telegram-bot-portfolio/bible_bot
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Подготовка базы данных
Поместите файл `bible.fb2` в корневую папку проекта, затем выполните:
```bash
python build_db_v3.py
python fix_db.py
```
*Это создаст файл `bible.db` с ~37 000 стихов и правильным каноническим порядком книг.*

### 3. Запуск Веб-приложения
```bash
python app.py
```
Откройте в браузере: `http://localhost:5000`

### 4. Запуск Telegram-бота
1. Откройте `bot.py` и вставьте свой токен от @BotFather в переменную `BOT_TOKEN`.
2. Запустите:
```bash
python bot.py
```

## 🧠 Логика умного поиска
1. **Одно слово** (например, `Бог`): Используется SQL `REGEXP` с границами слова `\b`. Находит только самостоятельные слова, игнорируя части других слов (не найдёт "богатырь").
2. **Несколько слов** (например, `Господь созиждет`): Используется комбинация `LIKE '%слово1%' AND LIKE '%слово2%'`. Находит стихи, где присутствуют все указанные слова в любом порядке, что компенсирует возможные различия в переносах строк или точном порядке слов в оригинальном FB2.
